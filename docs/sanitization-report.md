# 脱敏说明

## 已移除或泛化

- 公司、部门、项目和业务名称
- 内部 Git 域名、内部包名和专有组件库名
- 人员姓名、本机绝对路径和账号信息
- 内部设计平台、预览工具和发布系统名称
- 真实业务案例、业务页面、真实 token 数值和统计数据
- 与单一仓库强绑定的目录、端口、脚本和路由

## 保留内容

- 三个 Skill 的职责边界和调用关系
- 0-1 与已有项目的识别逻辑
- Project Adapter 的生命周期和防漂移机制
- 技术方案 spec 的确认卡点
- Design System 的分层产物结构
- 多方案、渐进披露和真实预览的决策逻辑
- 实现后的质量检查与交付沉淀

## 检查原则

发布前对整个目录执行关键词与路径扫描，并人工复核所有示例。任何来源不明或与具体组织绑定的内容都不进入公开版。
