# 选择后返回宿主：交付与验收

> 历史方案/验收记录：保留当时的环境、实现与测试边界，不作为当前操作指南。当前职责、链路和能力状态以 [产品链路](product-flow.md) 为准，实际操作见 [GUI 使用说明](design-builder.md)。

2026-10-06：GUI 不再输入业务需求。选择组件库、官网参考或不使用预设后，保存当前项目配置，再尝试打开启动时绑定的原宿主会话。保存完成页是跳转兜底，不是新的聊天页；已绑定时保留返回链接，未绑定时说明手动返回方式。

服务器支持 `--host-thread UUID`，在宿主环境启动时默认读取 CODEX_THREAD_ID；直接 createGuiServer 默认不绑定。会话绑定只保留在当前服务器实例中，不写入可移植项目配置。没有调用 turn/start、启动 Agent 或尝试向已有会话预填文字。

选择时标记 requirementSource=host，并清空旧 intent。配置记录目标项目绝对路径。原 API 兼容旧调用。Skill 规则要求每次重新读取最新选择，以本次用户消息为需求依据，旧 intent 仅为草稿。仓库 Skill 已更新，其他项目中此前复制安装的 Skill 需按正常更新方式同步；不要假定磁盘改动已经重新加载到一个正在运行的 Agent。

## 已验证

- `npm test`：82 项通过，包括选择持久化、冲突不覆盖、旧输入兼容、清空旧需求、项目真实路径、会话 ID 校验、缺少宿主绑定、诊断及安装回归。
- JS 语法检查与 git diff --check 通过。
- 实际浏览器隔离项目：不使用预设 → 保存完成页 → 刷新保留选择，明确显示未绑定宿主提示。未改用户正在使用的 selection 文件。
- 实际 4174 页面：我的项目显示 Apple、原会话深链、目标项目路径；业务需求输入框已移除。截图 `/tmp/design-builder-return-to-host.png`。
- 当前 4174 服务重新启动并明确绑定本会话 UUID。

## 未验证边界

保存后外部协议导航是尝试，不是自动发送或已收到消息。桌面 App 受电脑使用限制，不能截图检查浏览器→App 的完整跳转；已核验页面实际链接，但未宣称端到端自动交接通过。浏览器拦截时用户可点击返回入口。测试没有向宿主提交构建任务，因用户需求应在宿主另行输入。

从 GitHub 获取仓库到首次启动 GUI 的全流程不在本次实现范围；打开目录不会自行执行命令。启动入口见 design-builder.md。没有改变原设计系统构建、Gallery 和业务交付阶段。
