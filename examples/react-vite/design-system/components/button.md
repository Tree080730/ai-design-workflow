# Button (candidate)

Source: `src/components/Button.tsx`. Gallery: `/#component-button`.

Primary and secondary variants use semantic action/background/text tokens. Native button attributes are forwarded; default type is button. Loading sets aria-busy and disables activation. Disabled uses native disabled behavior. Keyboard activation follows native button semantics. Local Gallery counter verifies activation and reset; loading is a fixed specimen, not an asynchronous backend demonstration. No business requests or persistence.
