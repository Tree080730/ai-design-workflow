# TextField (candidate)

Source: `src/components/TextField.tsx`. Gallery: `/#component-text-field`.

Native input with label; generated id supports repeated instances. Props retain input behavior. Error text is associated through aria-describedby and aria-invalid; disabled is native. Gallery covers default, disabled and error specimens. Uses semantic text/background/action, spacing and radius tokens. This starter error style uses an explicit message and dashed border; no unconfirmed error color is invented.
