# React + Vite Adapter 示例

该文件展示 Adapter 的填写粒度，不代表实际项目事实。

```markdown
# Project Adapter

- 项目模式：已有项目
- 技术栈：React + TypeScript + Vite
- 包管理器：npm
- 最近核验：YYYY-MM-DD

## 命令
- 安装：npm install
- 开发：npm run dev
- 构建：npm run build
- 静态检查：npm run lint
- 测试：以 package.json 为准

## 目录映射
- 页面：src/pages/
- 通用组件：src/components/
- 样式与 token：src/styles/tokens.css
- 路由：src/App.tsx
- 设计系统：design-system/

## 复用顺序
1. 当前项目已有组件和页面模式。
2. design-system 已登记资产。
3. 项目已安装的 UI 库。
4. 新增资产并同步文档。

## 交付
- Spec：.design-workflow/specs/{date}-{slug}.md
- 预览：npm run dev 输出的实际地址
- 交付文档：deliverables/{date}-{slug}/TASK-SUMMARY.md
```
