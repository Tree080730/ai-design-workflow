# Token 扫描规则

## 默认范围

检查 CSS、SCSS、Less、CSS-in-JS，以及 JSX、TSX、Vue、Svelte 中的样式值。排除依赖、构建产物、快照、压缩文件和 token 定义文件自身。

## 重点属性

- 颜色：十六进制、rgb/hsl、渐变和透明色。
- 字体：字号、字重、行高和字体族。
- 空间：margin、padding、gap 和定位偏移。
- 形状：圆角、边框和阴影。
- 层级：z-index。
- 动效：duration、easing、distance 和 delay。

## 判断步骤

1. 当前项目是否已有语义相同的 token。
2. 该值是否属于图形几何、图片处理或第三方组件覆盖。
3. 是否重复出现并代表同一语义，而非偶然数值相同。
4. 替换是否会改变主题、继承、单位或响应式行为。

## 建议分级

| 级别 | 条件 | 行动 |
|---|---|---|
| P0 | 明确绕过强制 token 或破坏主题 | 本次修复 |
| P1 | 存在准确的语义 token | 建议修复 |
| P2 | 重复出现但尚无稳定语义 | 先评估是否新增 token |
| 豁免 | 特殊几何、第三方覆盖或生成值 | 保留并记录原因 |

## 防止误报

- 不用数值最接近原则自动映射。
- 不把所有间距都强制 token 化；一次性布局计算可以保留局部值。
- 不修改 SVG path、canvas 绘图和数据可视化色阶，除非设计系统明确覆盖。
- 不批量替换前后缀相同但语义不同的变量。
